# Панель «Яндекс Музыка» в углу экрана

Мини-плеер поверх всех окон: обложка, название/артист, прогресс с перемоткой,
кнопки «Мне нравится» / назад / плей-пауза / вперёд. Цвета — жёлто-графитовая
гамма Яндекс Музыки. Панель без рамки, всегда в правом нижнем углу (можно
перетащить мышью), справа по клику — контекстное меню.

Панель появляется сама, как только запущена «Яндекс Музыка»: за этим следит
контролёр (`panel.py --watch`), который ставится в автозапуск Windows.

Готовый файл для установки: **[YandexMusicPanel-1.1.exe (Releases)](https://github.com/advonikdm/YandexMusicPanel/releases/latest)**
— 18 МБ, Windows 10/11 x64, Python не нужен.

![Панель](docs/screenshot.png)

Так она выглядит при масштабе экрана 150 % (реальный размер окна — 322×81 пикселя).

## Файлы

- `panel.py` — всё приложение: окно, SMTC, CDP-клиент для лайка и режимы установки.
- `start-panel.vbs` — тихий запуск контролёра из исходников через `pythonw.exe`
  (без консоли): панель появится, когда запущена «Яндекс Музыка».
- `config.example.json` — образец настроек; рабочий `config.json` создаётся на месте
  и в репозиторий не попадает (положение окна и масштаб у каждого свои).
- `docs\screenshot.png` — картинка для этого README.
- `panel.py` собирается в один `dist\YandexMusicPanel-1.1.exe` (~19 МБ); `dist\` и `build\`
  в репозитории нет — готовый файл лежит в Releases. Номер версии — часть имени файла.

## Настройки (`config.json`)

Лежит рядом с `panel.py` или рядом с `YandexMusicPanel-1.1.exe` (для установленного —
в `%LOCALAPPDATA%\YandexMusicPanel\`). Все ключи необязательные:

| ключ | что делает |
| --- | --- |
| `scale` | множитель размера панели; если ключа нет, подбирается по DPI экрана (144 → 1.5) |
| `x`, `y` | положение окна в экранных пикселях; пишется, когда перетащишь панель мышью |
| `cdp_port` | порт CDP для лайка, по умолчанию `9229` |
| `require_ym` | по умолчанию `true`: контролёр поднимает панель только когда запущено приложение «Яндекс Музыка»; `false` — поднимает сразу и всегда (сама панель, запущенная вручную, при этом не закрывается) |
| `stopped`, `disabled` | служебные ключи (пишет меню панели и `--uninstall`), руками их лучше не трогать |

Сбросить положение — контекстное меню панели (правый клик) → «Вернуть в правый нижний
угол», либо удалить `config.json`. Менять масштаб вручную обычно не нужно.


## Установка на другой компьютер

Один файл — `YandexMusicPanel-1.1.exe` из [Releases](https://github.com/advonikdm/YandexMusicPanel/releases/latest)
(в репозитории его нет, при сборке он попадает в `dist\`). Нужна Windows 10/11 x64, Python не нужен.

- Двойной клик (или запуск без параметров) = установка: файл копируется в
  `%LOCALAPPDATA%\YandexMusicPanel\`, в папку «Автозагрузка» кладётся
  `YandexMusicPanel.vbs` — при входе в Windows стартует контролёр, и он поднимает
  панель, когда в системе появляется «Яндекс Музыка». Масштаб (`scale`)
  подбирается автоматически под DPI экрана нового компьютера.
- Параметры: `--install` (переустановить), `--silent` (без окошек, для скриптов),
  `--run` (запустить панель из скачанного файла, не устанавливая),
  `--watch` (только контролёр: следит за приложением и держит панель),
  `--version` (показать версию и путь к установленному файлу),
  `--uninstall` (снять автозапуск, закрыть панель, удалить папку).
- Обновление версии: запуск `YandexMusicPanel-<новая>.exe` сам закрывает панель
  старой версии, удаляет её файл и кладёт на её место новый; имя файла в
  «Автозагрузке» (`YandexMusicPanel.vbs`) не меняется.
- Скачанный из интернета файл может заблокировать SmartScreen: свойства файла →
  «Отключить блокировку», либо «Выполнить в любом случае» при первом запуске.
- Лайк работает так же только при запущенной с ключом
  `--remote-debugging-port=9229` «Яндекс Музыке» — на новом компьютере это
  настраивается отдельно (см. выше).

## Запуск и сборка из исходников

Только Windows x64, Python 3.10+ (проверено на 3.12):

    pip install pillow winrt-Windows.Media.Control winrt-Windows.Storage.Streams
    pythonw panel.py            # панель один раз (или start-panel.vbs)
    pythonw panel.py --watch    # контролёр: панель вместе с приложением

Автозапуск для версии из исходников (тоже пишет `.vbs` в «Автозагрузку»):

    python panel.py --install --silent      # снять:  python panel.py --uninstall --silent

Повторный запуск игнорируется — в системе мьютексы `ymcorner_panel_single`
(панель) и `ymcorner_watch_single` (контролёр). pid обоих процессов записаны в
`.watch.pid` рядом с `panel.py`.
Остановить: контекстное меню панели → «Выйти» (панель не вернётся, пока
приложение не запустят заново), либо `python panel.py --uninstall --silent`
— закроет и панель, и контролёр.

Тот же один .exe после правок (`pip install pyinstaller`):

    python -m PyInstaller --noconfirm --clean --onefile --windowed ^
      --name YandexMusicPanel-1.1 --distpath dist --workpath build --specpath build ^
      --collect-all winrt panel.py

Номер версии в имени файла берётся из `VERSION` в `panel.py` — менять нужно и там,
и в команде сборки.

Обновить файл в релизе: `gh release upload v1.1 dist\YandexMusicPanel-1.1.exe --clobber`.

## Откуда данные и куда уходят команды

- Всё, кроме лайка: SMTC (System Media Transport Controls) через `pywinrt`,
  AUMID приложения — `ru.yandex.desktop.music`. Статусы: PLAYING=4, PAUSED=5.
- Позицию SMTC Яндекс отдаёт редко, поэтому прогресс в панели экстраполируется,
  база обновляется только при скачке больше 0.8 с.
- play / prev / next / seek — через SMTC; если сессии нет, панель шлёт
  медиа-клавиши (VK_PLAY_PAUSE, VK_PREV, VK_NEXT).
- **Лайк** отдельным каналом: CDP (Chrome DevTools Protocol) на
  `127.0.0.1:9229`. В SMTC команды «лайк» нет. Клиент написан на стандартной
  библиотеке (класс `Like` в `panel.py`).
  - Кнопка в DOM приложения: `[data-test-id="LIKE_BUTTON"]`, состояние —
    в атрибуте `aria-pressed`. Есть ещё `DISLIKE_BUTTON`.
  - Работает **только если приложение запущено с ключом**
    `--remote-debugging-port=9229`. Иначе сердечко серое, а по клику панель
    предлагает перезапустить Яндекс Музыку с этим ключом (то же — в
    контекстном меню панели).
  - После перезагрузки Windows или обычного запуска приложения лайк
    «отключается», пока не сработает перезапуск с ключом.

## Текущее состояние (проверено)

- Экран один, 3840×2160, DPI 144 (масштаб 150 %), панель 215×54 логических
  пикселей (было 430×108; на экране — 322×81), правый край у угла экрана.
- Проверено на этой машине: `YandexMusicPanel.vbs` в «Автозагрузке» поднимает
  контролёр, контролёр поднимает панель в правом нижнем углу (24 пикселя от
  края), панель возвращается через ~3 с, если её закрыть, и не возвращается
  после «Выйти», пока приложение не перезапущено.
- Проверено: отображение трека/артиста/обложки, play-пауза, переключение
  треков, перемотка, лайк и снятие лайка прямо из панели (состояние
  подхватывается примерно за секунду и следует за сменой трека).

## Версии

- **1.1** — установочный файл с номером версии (`YandexMusicPanel-1.1.exe`),
  панель поднимается вместе с приложением (контролёр `--watch` и `.vbs` в
  «Автозагрузке»), установка поверх версии без номера, ключ `--version`,
  «Версия 1.1» в контекстном меню панели, угол экрана как запасная позиция,
  если сохранённая не влезает в экран.
- **1.0** — панель в углу, SMTC, лайк через CDP, установка одним файлом.

## Что можно доделать

- Автозагрузка Яндекс Музыки с `--remote-debugging-port=9229`, чтобы лайк работал
  сразу после включения компьютера (автозапуск самой панели уже делает установщик).
- Кнопка «не нравится» (дизлайк), хоткеи, компактный режим, автоскрытие.
