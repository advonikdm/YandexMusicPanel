# Панель «Яндекс Музыка» в углу экрана

Мини-плеер поверх всех окон: обложка, название/артист, прогресс с перемоткой,
кнопки «Мне нравится» / назад / плей-пауза / вперёд. Цвета — жёлто-графитовая
гамма Яндекс Музыки. Панель без рамки, всегда в правом нижнем углу (можно
перетащить мышью), справа по клику — контекстное меню.

Готовый файл для установки: **[YandexMusicPanel.exe (Releases)](https://github.com/advonikdm/YandexMusicPanel/releases/latest)**
— 18 МБ, Windows 10/11 x64, Python не нужен.

## Файлы

- `panel.py` — всё приложение (один файл, только стандартная библиотека + pywinrt;
  PIL используется для обложек).
- `config.json` — `scale` (1.5 = 150 %), `x`, `y` — положение окна.
- `start-panel.vbs` — тихий запуск через `pythonw.exe` (без окна консоли).
- `config.json` создаётся на месте (его нет в репозитории): положение окна и
  масштаб свои у каждого компьютера.
- `dist\YandexMusicPanel.exe` — собранный один файл (~19 МБ), его нет в репозитории:
  он лежит в Releases. `build\` — временное для сборки (тоже не в репозитории).

## Установка на другой компьютер

Один файл — `YandexMusicPanel.exe` из [Releases](https://github.com/advonikdm/YandexMusicPanel/releases/latest)
(в репозитории его нет, при сборке он попадает в `dist\`). Нужна Windows 10/11 x64, Python не нужен.

- Двойной клик (или запуск без параметров) = установка: файл копируется в
  `%LOCALAPPDATA%\YandexMusicPanel\`, в папку «Автозагрузка» кладётся
  `YandexMusicPanel.vbs` (запуск при входе в Windows), панель стартует сразу.
  Масштаб (`scale`) подбирается автоматически под DPI экрана нового компьютера.
- Параметры: `--install` (переустановить), `--silent` (без окошек, для скриптов),
  `--run` (запустить панель из скачанного файла, не устанавливая),
  `--uninstall` (снять автозапуск, закрыть панель, удалить папку).
- Скачанный из интернета файл может заблокировать SmartScreen: свойства файла →
  «Отключить блокировку», либо «Выполнить в любом случае» при первом запуске.
- Лайк работает так же только при запущенной с ключом
  `--remote-debugging-port=9229` «Яндекс Музыке» — на новом компьютере это
  настраивается отдельно (см. выше).

Собрать заново после правок в `panel.py`:

    python -m PyInstaller --noconfirm --clean --onefile --windowed ^
      --name YandexMusicPanel --distpath dist --workpath build --specpath build ^
      --collect-all winrt panel.py

Запуск: `pythonw panel.py` (или `start-panel.vbs`). Повторный запуск
игнорируется — в системе мьютекс `ymcorner_panel_single`. Остановить:
завершить процесс `pythonw.exe`, у которого в командной строке `panel.py`.

## Откуда данные и куда уходят команды

- Всё, кроме лайка: SMTC (System Media Transport Controls) через `pywinrt`,
  AUMID приложения — `ru.yandex.desktop.music`. Статусы: PLAYING=4, PAUSED=5.
- Позицию SMTC Яндекс отдаёт редко, поэтому прогресс в панели экстраполируется,
  база обновляется только при скачке больше 0.8 с.
- play / prev / next / seek — через SMTC; если сессии нет, панель шлёт
  медиа-клавиши (VK_PLAY_PAUSE, VK_PREV, VK_NEXT).
- **Лайк** отдельным каналом: CDP (Chrome DevTools Protocol) на
  `127.0.0.1:9229`. В SMTC команды «лайк» нет. Клиент написан на стандартной
  библиотеке (класс `Like` в `panel.py`).
  - Кнопка в DOM приложения: `[data-test-id="LIKE_BUTTON"]`, состояние —
    в атрибуте `aria-pressed`. Есть ещё `DISLIKE_BUTTON`.
  - Работает **только если приложение запущено с ключом**
    `--remote-debugging-port=9229`. Иначе сердечко серое, а по клику панель
    предлагает перезапустить Яндекс Музыку с этим ключом (то же — в
    контекстном меню панели).
  - После перезагрузки Windows или обычного запуска приложения лайк
    «отключается», пока не сработает перезапуск с ключом.

## Текущее состояние (проверено)

- Экран один, 3840×2160, DPI 144 (масштаб 150 %), панель 215×54 логических
  пикселей (было 430×108; на экране — 322×81), правый край у угла экрана.
- Проверено: отображение трека/артиста/обложки, play-пауза, переключение
  треков, перемотка, лайк и снятие лайка прямо из панели (состояние
  подхватывается примерно за секунду и следует за сменой трека).

## Что можно доделать

- Автозагрузка Яндекс Музыки с `--remote-debugging-port=9229`, чтобы лайк работал
  сразу после включения компьютера (автозапуск самой панели уже делает установщик).
- Кнопка «не нравится» (дизлайк), хоткеи, компактный режим, автоскрытие.
